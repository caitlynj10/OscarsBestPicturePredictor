# Oscars Best Picture Prediction Algorithm 
This model I created during my time studying abroad at King's College London where I took a class named _Statistical Modeling_. The final project for this class was to create a prediction algorithm that will correctly predict the Best Picture Winner for the 2025 Oscars. We were given a dataset containing a list of all movies that have ever been nominated for Best Picture. In the dataset, we can find all historical data for each movie, including genre, various category nominations and wins, and other screen awards received. Using this dataset and a stepwise prediction model, I was able to determine the most important features that the Best Picture winner would likely have based on the model that produced the lowest AIC, and using that, I was able to correctly predict the 2025 Best Picture winner.
